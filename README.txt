ЯНДЕКС МУЗЫКА — ПАТЧ «КРЕСТИК = СВЕРНУТЬ В ТРЕЙ»
========================================================================

ЧТО ДЕЛАЕТ ПАТЧ
----------------
По умолчанию приложение сворачивается в трей при нажатии на крестик (X)
ТОЛЬКО когда играет музыка. Если музыка не играет — программа полностью
закрывается.

После патча: нажатие на крестик ВСЕГДА сворачивает приложение в трей,
независимо от того, играет музыка или нет. Приложение остаётся висеть
в трее, музыка может продолжать играть.

КАК ЗАПУСТИТЬ (Windows 10 / 11)
-------------------------------
Способ 1 (самый простой):
  Двойной клик по файлу "1_Установить_патч.cmd"
  (если браузер/архиватор переименовал файлы — запустите .cmd из папки)

Способ 2 (через PowerShell):
  Правой кнопкой по YandexMusicTrayPatch.ps1 -> "Выполнить с помощью PowerShell"
  Если появляется ошибка о политике выполнения, запустите в командной строке:
  powershell -ExecutionPolicy Bypass -File YandexMusicTrayPatch.ps1

Скрипт сам:
  1. Найдёт установленную Яндекс Музыку (через реестр / стандартные пути)
  2. Остановит приложение, если оно запущено
  3. Создаст резервные копии обоих файлов (app.asar и exe)
  4. Внесёт изменения (несколько байт)
  5. Запустит приложение обратно

КАК ТЕПЕРЬ ВЫЙТИ ИЗ ПРИЛОЖЕНИЯ ПОЛНОСТЬЮ
----------------------------------------
  - Правой кнопкой по иконке в трее -> "Выход"
  - или закрыть окно через Alt+F4 (это по-прежнему закрывает полностью)

ОТМЕНА ПАТЧА
------------
  Двойной клик по "2_Убрать_патч.cmd" — вернёт оригинальные файлы
  из резервных копий (побайтово, с проверкой).

ВАЖНО ЗНАТЬ
-----------
1. После КАЖДОГО обновления приложения патч слетает (обновление
   заменяет файлы). Просто запустите "1_Установить_патч.cmd" ещё раз.

2. Патч изменяет exe-файл на 1 байт (выключает внутреннюю проверку
   целостности Electron, иначе изменённый app.asar не запустится).
   Из-за этого цифровая подпись exe становится недействительной —
   это нормально для любого бинарного патча. Некоторые антивирусы
   могут отнестись к этому настороженно — это ложное срабатывание.

- Скрипт не нашёл приложение: запустите командную строку и укажите путь:
    powershell -ExecutionPolicy Bypass -File YandexMusicTrayPatch.ps1 -InstallDir "C:\Users\<имя>\AppData\Local\Programs\ymusic"
  (путь к папке, где лежит "Яндекс Музыка.exe" и папка resources)
- Приложение ставилось "для всех пользователей": запустите скрипт
  от имени администратора.
